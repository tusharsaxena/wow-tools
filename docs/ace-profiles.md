# Ace3 Profile Manager

[← Back to the main page](../README.md)

Many addons (ElvUI, Details, HandyNotes and hundreds more) keep their settings in Ace3 profiles, and over the years
those pile up: profiles nobody uses, characters you deleted long ago, every alt on its own copy of the same setup.
The Ace3 Profile Manager reads your `WTF` folder, shows each addon's profiles and which characters use them, and lets
you delete, rename and copy profiles, move characters to another profile and remove characters that no longer exist.
It changes nothing until you apply, backs up every file it edits first, and can undo the last change.
